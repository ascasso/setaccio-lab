# 2026-07-11

## Expectation-aware Tool Search comparison protocol

### Summary

- Added a dedicated public-safe Java tool benchmark case corpus covering arithmetic, fixed time, catalog lookup, multi-step execution, no-match behavior, domain-tool abstention, and deterministic callback failure.
- Added additive prompt expectations for required and forbidden executed tools, required output terms, and required tool-response terms.
- Added normalized Tool Search observations for search query, completion state, and discovered tool names, plus named per-row assertions and `contractPassed` without introducing an aggregate advisor winner score.
- Added explicit repetitions, temperature, base seed, optional token limit, and comparison-order request settings. Comparison runs are paired and sequential, and default repetitions alternate which advisor runs first.
- Recorded repetition, effective seed, comparison pair, and pair execution order on each tool benchmark row.
- Added a deterministic failure fixture and kept every automated test mocked and offline.
- Made result writing collision-safe with nanosecond timestamps, unique run identifiers, and non-overwriting file creation.
- Refreshed the README, environment guide, test plan, changelog, and repo-local agent guidance to match the implemented benchmark surfaces.
