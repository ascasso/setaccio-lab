## Private vision human-review preparation

- Added the offline-only `visionHumanReviewPrepare` task to replace the manual
  verification, comparison, corpus lookup, and response-grouping sequence with
  one explicit command.
- The task requires explicit baseline, candidate, and fixed ignored corpus
  paths. It verifies both evidence directories, enforces deterministic
  comparability, and requires the current corpus MIME/BLAKE3 identities to
  match the saved inputs before writing anything.
- It writes one ignored, non-overwriting `HUMAN-REVIEW.md` worksheet under
  `build/vision-human-review/`, including private references, local image links,
  paired raw responses, and blank fields from the committed rubric. Exact
  successful repetitions are shown once; differing or failed repetitions stay
  separate.
- The task does not start Spring, contact Ollama, select runs, score semantics,
  or make an adopt/revise/reject decision.
- Its custom Gradle wrapper receives configured directory properties and does
  not call `Task.project` during execution. The earlier TODO remains open for
  the pre-existing matrix and smoke wrappers that still use that deprecated
  pattern.
