## Opt-in local Tool Search smoke automation

- Added a dedicated `ToolSearchSmokeTask` build task and isolated `toolSearchSmoke` source set so live verification remains outside production code, default tests, `check`, `build`, and default CI.
- Added the explicit `./gradlew toolSearchSmoke --model=<already-installed-model> [--case-ids=...]` workflow. The model is required, semantic case IDs and 1-based ordinals are supported, and missing, blank, duplicate, unknown, or out-of-range selections fail before Spring contacts Ollama.
- The runner uses `ToolBenchmarkCases.defaults()` and the complete `ToolBenchmarkCases.toolNames()` fixture set directly, starts a non-web local Spring context, performs one deterministic paired comparison, forces the regex Tool Search index, and verifies that the effective Ollama pull strategy is `never`.
- Added independent trace-integrity analysis for Spring AI's scalar-array, textual-singleton, and object `toolReferences` response forms. Startup/invocation errors, malformed results, missing trace linkages, and raw-versus-normalized discovery mismatches are hard failures; model behavior categories remain diagnostic.
- Added the required console buckets and warning for no search call, zero matches, non-empty discovery, discovery mismatch, required discovery without execution, and required execution with an output-contract failure.
- Added 11 isolated offline smoke tests for selection, supported wrapper forms, trace integrity, summary categories, invocation failure, malformed data, and non-blocking model behavior. Extended the default trace-evaluator regression coverage for Spring AI's `arg0` query field and a completed zero-match response.
- Documented the task in `README.md`, `docs/ENVIRONMENT.md`, `docs/TEST-PLAN.md`, and `CHANGELOG.md`.
- Verified `./gradlew help --task toolSearchSmoke`, missing-model rejection, invalid ordinal rejection, `./gradlew :setaccio-lab:test :setaccio-lab:toolSearchSmokeTest`, the full three-module build, and `git diff --check`.
- Did not run the live smoke task during this slice because no already-installed model was explicitly selected. No model was pulled and no remote provider was called.
