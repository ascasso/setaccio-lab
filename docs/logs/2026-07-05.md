# 2026-07-05

## Local chat benchmark

### Summary
- Added a local-only `POST /api/lab/chat` JSON endpoint for simple Ollama chat completion benchmark runs without tools.
- Added chat benchmark request/result/row models that capture suite/provider metadata, prompt id/text, advisor mode, latency, token usage when Spring AI exposes it, final output, and failure details.
- Reused the existing lab result writer, Caffeine cache manager, and executor pattern, with results persisted as `*-chat.json` under the configured lab results directory.
- Added default public-safe text prompts plus controller validation for explicit prompt lists, missing models, blank prompt text, and unsupported advisor modes.
- Documented that local Ollama calls use the required comma-separated `models` request field, while `OLLAMA_MODEL` remains the app-level default that currently resolves to `gemma4:e2b`.
- Kept automated coverage mocked/offline; no live Ollama integration tests or default/CI live provider paths were added.
- Documented local chat benchmark usage in the README, environment guide, test plan, and changelog.
