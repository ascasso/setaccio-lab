# Release 0.1.0

The project owner authorized cutting the first release and decided its two
open parameters directly: version `0.1.0`, and leave `origin/master` where it
is rather than fast-forwarding it to `origin/develop` as part of this release.
This follows `docs/DEFERRED-WORK.md`'s "Release, tag, and promotion" gate,
which requires deciding version, changelog release entry, and tag together
under a separately authorized promotion/release workflow.

## What this release is

Root `build.gradle`'s `allprojects` block has carried `version =
'0.1.0-alpha.2'` since it was first set, unbumped and never tagged. This
release promotes it to `0.1.0` — the version the owner chose, and the same
number the project was already tracking toward, minus the alpha qualifier. No
consumer reads this property anywhere in the build (`grep` for
`archiveVersion`, `project.version`, `rootProject.version`, or `${version}`
across every `*.gradle` file found nothing), so the bump changes no runtime or
packaging behavior.

`CHANGELOG.md`'s `[Unreleased]` section — everything recorded since the
project's tracked history began — is cut into a new `## [0.1.0] - 2026-09-04`
section, with a fresh empty `[Unreleased]` left above it for future work. This
is a changelog reorganization only: no entry's text changes, no evidence is
touched, and no closeout recorded in any of those entries is withdrawn or
reinterpreted by being labeled a release.

## What this release does not do

It does not fast-forward `origin/master`; that was explicitly declined for
this release. It does not merge, rebase, or otherwise change
`feature/tool-compatibility-plan`'s relationship to `origin/develop`. It does
not rerun, repair, replace, reanalyze, or publish any retained evidence, and
it does not touch any closed suite. It authorizes creating a local annotated
tag `v0.1.0` on the commit that makes this change; it does not authorize
pushing that tag, pushing any commit, opening a pull request, or merging —
those remain separately gated and were not instructed in this session.
