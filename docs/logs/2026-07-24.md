# 2026-07-24

## Shared benchmark evidence lifecycle foundation

- Added plain Java evidence primitives under
  `com.setaccio.lab.evidence` for reuse by benchmark-specific runners.
- Added a versioned manifest envelope that records:
  - suite and run identity;
  - generation time;
  - Git commit and working-tree state;
  - Spring Boot and Spring AI versions;
  - execution engine and suite-provided settings;
  - relative artifact paths, roles, byte sizes, and SHA-256 digests.
- Added atomic unique run-directory allocation and named-directory creation that
  refuses to overwrite an existing run.
- Added non-overwriting `manifest.json` read/write support with strict manifest
  version and unknown-field handling.
- Added streaming SHA-256 artifact description and offline verification for:
  - missing artifacts;
  - modified sizes or digests;
  - empty artifacts;
  - duplicate declarations;
  - undeclared files;
  - absolute, parent-traversing, or cross-platform absolute paths;
  - symbolic links and artifacts outside the run directory.
- Added Git and framework provenance detection without starting a Spring
  application context.

### Design boundaries

- Kept suite-specific benchmark rows and analyzers outside the shared manifest
  lifecycle; this is not a plugin framework or universal result schema.
- Kept BLAKE3 assigned to benchmark input identity and SHA-256 assigned to
  generated artifact integrity.
- Added no hostname, absolute-path, credential, or raw environment fields to
  the manifest envelope.
- Added no dependency, provider integration, live model call, Testcontainers
  runtime work, MCP code, UI, or Embabel code.
- Existing Tool Search and vision writers do not use the shared lifecycle yet.
  Tool Search adoption, legacy manifest handling, offline saved-run
  verification, and summary regeneration remain the next slice.

### Documentation

- Updated `CHANGELOG.md` with the durable evidence-lifecycle capability.
- Updated `docs/TEST-PLAN.md` with the offline integrity and public-safety

- Updated `AGENTS.md` current-state and near-term sections without claiming
  that an existing benchmark writer has migrated.
- Did not update `docs/ENVIRONMENT.md` because this slice adds no user-facing
  command or environment variable.
