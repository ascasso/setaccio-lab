# 2026-07-25

## Local vision corpus contract and privacy boundary

- Added the tracked version 1 vision corpus template with six stable,
  non-sensitive case IDs for:
  - a clear single subject;
  - a complex scene;
  - a text-heavy image;
  - a low-quality image;
  - an ambiguous image;
  - a file-organization image.
- Defined one fixed local layout under
  `setaccio-lab/local/vision-corpus/`, with `cases.json` and case-ID-based image
  filenames under `images/`.
- Explicitly ignored the complete local corpus directory so personal source
  images and filled observations remain untracked.
- Defined per-case metadata for MIME type, BLAKE3 input identity, a human
  reference observation, expected concepts, unsupported details, deliberate
  limitations, and privacy-review state.
- Required sensitive-content and EXIF/GPS review plus explicit user approval
  before any exact image or derivative can become tracked.
- Added an offline contract test that locks the template version, fields, safe
  IDs, relative image paths, and unapproved privacy defaults.
