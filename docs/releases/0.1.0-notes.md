# Setaccio Lab 0.1.0

First source release of the Apache-2.0 Setaccio Lab: a Java workspace for
explicit AI experiments, provider-free tests, and verifiable saved results.

## Included

- `setaccio-core`: a small, Spring-free Java library with BLAKE3 utilities.
- `setaccio-lab`: a Spring Boot / Spring AI evaluation app with local vision,
  chat, tool-calling, and deterministic evaluation endpoints.
- Opt-in experiment suites for vision, tool compatibility, chat portability,
  fact checking, retrieval, grounded answers, relevancy evaluation, and
  reasoning diagnostics.
- Versioned prompts and public fixtures, explicit invocation settings and
  model identities, non-overwriting private evidence directories, and
  standalone offline verification and deterministic reanalysis.
- `setaccio-testcontainers`: an optional integration-harness skeleton,
  independent of the normal lab build's Docker requirements.

## Build and run

Use Java 25 for the Gradle launcher as well as compilation and tests, and
the included Gradle Wrapper (Gradle 9.7.1 in this release).
The release pins Spring Boot 4.1.1 and Spring AI 2.0.1.

```bash
./gradlew :setaccio-core:build :setaccio-lab:build :setaccio-testcontainers:build
./gradlew :setaccio-lab:bootRun --args='--spring.profiles.active=local'
```

The lab listens on port 8082. Live model calls require explicit local setup;
default builds and tests do not call providers or require credentials.
See the README and `docs/ENVIRONMENT.md` in the tagged source for setup and
opt-in experiment commands.

## Scope and limitations

This is a research harness and reference server. Its recorded experiments
support bounded protocol observations, not general model quality, factuality,
reliability, ranking, or selection claims. Some historical private evidence
was lost; the documented owner waivers preserve the closeouts without
recreating that evidence or claiming current reproducibility.

Private corpora, raw model outputs, credentials, and private Setaccio product
code are excluded. Published evidence examples contain permitted deterministic
summaries and manifests only and cannot replace complete private saved runs
for offline verification. No models are bundled, and no MCP implementation is
included. No Maven repository or binary package publication is part of this
source release.
